CONTRIBUTING TO docker-shrink

Guidelines

1. Single Contributor Model
Authored and maintained by Dhani078.

2. Code Standards
- Zero third-party dependencies: Standard Node.js library only.
- Strict limit: Under 200 lines of code per source file.
- Node.js >= 20.0.0 LTS compatibility.
- Zero markdown hash headings and zero asterisks in all documentation.

3. Testing Requirements
Test suites must include before-and-after sample Dockerfiles for Node.js, Python, Go, and static HTML.
